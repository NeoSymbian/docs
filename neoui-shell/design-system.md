# Design system

**Status: built (UI v2, 2026-11-17).** It covers the tokens, layout, glyphs, display digits, app tiles and
components every neoui screen and app uses. The canvas's **Design system** page (7 sheets) follows the code. This
page replaces `neoui/design/DESIGN.md` (2026-11-06, "Belle, modernized"), which is stale: it lists 26 glyphs and a
1.8 digit stroke. The hub is [README.md](README.md).

**Where the code is** (neoui):
- `ui/theme.slint`: the tokens;
- `ui/components/`: the components (`kit.slint` exports them, as `@neoui/kit.slint`);
- `ui/icons/sys/` (glyphs), `ui/icons/apps/` (tiles) and `ui/icons/digits/`, all generated by `tools/make_icons.py`;
- `design/measured.json`: the raw Belle measurements (`tools/extract_design.py`).

## Principles (kept from DESIGN.md)
- Belle's structure, modernized:
  - a thin status bar;
  - an app grid;
  - the system parts drawn by the shell (status bar, key row or band, dialogs, keyboard, shade);
  - the header and footer drawn by the app with the kit ([kit.md](kit.md), K01);
  - a black canvas.
- **Only facts are reused** (sizes, proportions, colours, timings) from the Symbian^3 EPL layout data and from
  measured screenshots of an N8 running Belle. No Nokia artwork, icon, font or file is copied. The font is Inter (OFL)
  and every icon is original.

## Units and layout (`ds-layout`)
- **1 dp = min(width, height) / 360.** The Pixel 3a XL has 3 px per dp; Syborg (768 × 640) has 1.78.
- **The screen stack** (720 dp tall on the Pixel):

  | Mode | Stack |
  |---|---|
  | Buttons | status 25 · app 639 · key row 56 |
  | Gestures and N9 | status 25 · app 679 · band 16 |
  | Full screen | 720 |

  Inside an app: header 48 · content · footer 48.
- **Edge zones** 16 dp; the keyboard sits above the key row or the band.

## Glyphs (`ds-glyphs`, `ui/icons/sys/`, 84 today)
- **One grid and one weight:** 24 units, 1.8-unit strokes, round caps and joins; white, tinted in Slint with
  `colorize`.
- **Rasterised at build time** at 96 px.
- **The top panel needs these, which don't exist yet:** moon (Do not disturb), airplane, flashlight, rotate,
  hotspot, cast, nfc, screen record, no-SIM, mark-read. They are added in
  [top-panel.md](top-panel.md) TP0/TP1. (`bell`, `silent`, `vibrate`, `alarm`, `headset`, `charging`, `location`,
  `lock`, `privacy`, `bluetooth`, `wifi`, `data` exist.)

## Display digits (`ds-digits`, `ui/icons/digits/`)
- The big clocks (`BigClock`, the home clock, Clock's TimeHero) use 11 SVGs (0–9, colon), not text: SDF text breaks
  up at clock sizes.
- **Grid:** digits are 14 × 24; the colon is 6 × 24.
- **Stroke:** 1.5 units (the glyphs use 1.8), round caps.
- **Rasterised** at 240 px.
- **Spacing:** h × 0.07; `lead-zero false` drops the hour's leading 0.

## App tiles (`ds-app-icons`, `ui/icons/apps/`, 15)
- 14 tiles are generated from one base colour each (lit from the top, radius 26 of 96, a faint inner rim):
  - Phone #22b46a, Messages #2f80ed, Contacts #f2994a, Browser #1fa9c4, Camera #5b6472;
  - Photos #14a37f, Music #e04e9b, Calendar #e5484d, Clock #8656e8, Files #e2a92a;
  - Settings #6b7688, Terminal #2b2f36, Old apps #4f6b8a, Apps (dock) #3a4150.
- Dev tools is hand-written.
- **Sizes:** 72 dp in the grid, 54 in the dock, 22 in small headers.

## Icon formats (`ds-icon-formats`)
- **SVG glyphs** for the system, apps and the kit.
- **ENTRY icons:** ARGB pixels up to 128 × 128, with a `w, h` header (`decode_entry_icon`) for launcher entries.
  The top panel's BLOBs (avatars, art) reuse this encoding.
- **Old apps:** their own MBM/SVG, bridged by LEGACY.

## Components (`ds-components`, `ui/components/`)
- **Kit, for apps:**
  - headers: Header, SubHeader, FormHeader, SearchHeader, SelectionHeader;
  - Footer, TabPages, Menu, NeoList and ListRow, TextField, Switch, Button, ChoiceSheet;
  - Keypad, Fab, Bubble, Composer.

  The reference is [kit.md](kit.md#the-kit-component-by-component).
- **Shell only:** StatusBar, KeyRow and Band (`frame.slint`), the shade (`shade.slint`), Toast (`feedback.slint`),
  the keyboard, the power menu, sheets and layers.
